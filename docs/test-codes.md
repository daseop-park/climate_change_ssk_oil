# 테스트 코드

> ⚠️ **실제 발급된 코드를 이 파일에 적지 마세요.**
> 사전 배정 모델이라 코드↔상품 매핑이 곧 정답표입니다. 저장소에 올라가면 어떤 코드가 1등인지
> 그대로 조회할 수 있습니다. 실코드는 `out/` (gitignore 대상)로만 뽑으세요.

코드 형식은 **영문 3 + 숫자 3** (`ABC-123`) 입니다.
입력창은 소문자·하이픈 없이 쳐도 정규화합니다. (`abc123` → `ABC-123`)

---

## 실제 코드 (DB 발급) — 2단계 이후

1단계에서 배치 발급 파이프라인이 준비됐습니다.

```bash
npm run db:seed                                   # 경품 6종
npm run db:issue -- --batch <이름> --dry-run       # 미리보기
npm run db:issue -- --batch <이름> --out out/codes.csv
npm run db:verify -- --batch <이름>                # 고유성·형식·분배·셔플 검증
npm run db:stock                                  # 상품별 재고 현황
```

발급된 코드는 DB에만 있고, 목록이 필요하면 `--out` 으로 CSV를 뽑습니다.
**단, 프론트엔드가 DB를 읽는 것은 2단계부터입니다.** 그 전까지 화면은 아래 더미 코드로 동작합니다.

## 더미 코드 (프론트엔드 데모용) — 3단계에서 폐기

현재 화면의 당첨 결과는 `src/lib/design/redeem.ts` 의 `outcomeFor` 가 **코드 해시**로 결정합니다.
따라서 아래 코드는 입력할 때마다 항상 같은 결과가 나옵니다. **꽝은 없습니다.**
