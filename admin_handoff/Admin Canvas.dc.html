개인정보

성함도 전화번호와 동일하게 nameEnc(AES-256-GCM) + nameHash(HMAC)로 저장하고, 목록에는 가운데 글자를 가린 형태(김O은)로만 표시합니다. 성함은 경품 수령 시 본인 대조용이며, 번호와 함께 복합 조회로 씁니다.

테이블에는 항상 마스킹된 번호만 렌더합니다. 평문 복호화는 별도 버튼 → 사유 입력 → 감사 로그 기록 후에만 허용하세요. 목록 API 응답에 평문을 절대 포함하지 마세요.

검색은 평문이 아니라 HMAC 해시로: 입력값을 정규화 → HMAC → phoneHash 인덱스 조회.

확률 · 재고

확률은 별도 컬럼이 아니라 가중치 ÷ 합계로 항상 파생 계산합니다. 두 값을 각각 저장하면 반드시 어긋납니다.

재고 0이 되면 추첨 대상에서 제외되고 나머지 가중치로 자동 재정규화. 미당첨이 없으므로 전 경품 소진 = 이벤트 종료입니다. 최하위 등급 재고를 총 코드 수 이상으로 확보하거나, 소진 시 응답을 따로 설계하세요.
